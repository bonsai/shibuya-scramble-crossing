# shibuya-scramble-crossing

渋谷スクランブル交差点の写真を集め、**街は 3D・人は写真のまま**「ここにいた」を残す。

- **PC**: 3DGS の街  
- **スマホ**: 軽いポリゴンの街  
- **人**: 立体化せず、写真を空間に浮かせる  
- **データ**: Cloudflare R2 → Colab で学習

進捗・手順・タスクはすべて **[Issues](https://github.com/bonsai/shibuya-scramble-crossing/issues)**（カンバン）で管理。

```bash
npm install && npm run dev   # 投稿 UI + API
# Colab: colab/r2_3dgs_template.ipynb
```
