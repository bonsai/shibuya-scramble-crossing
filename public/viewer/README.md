# 渋谷スクランブル 3D 街ビューア

渋谷スクランブル交差点の 3D 街（GLB / 3DGS）を表示するための WebGL ビューア実装です。
ローカルまたは Cloudflare Worker 上で静的アセットとして配信され、ブラウザ単体（ノービルド ES Module）で動作します。

- 実行方法: 静的 Web サーバー（例: `npx serve public`）でホストし `/viewer/` にアクセスします。

## 機能・ステージ切替

1. **PC / モバイル 自動判定**:
   - デスクトップ (PC): 3D Gaussian Splatting (`city_gs`)
   - モバイル / スマホ: 軽量 GLB ポリゴンモデル (`city_glb`)
2. **URLパラメータによるオーバーライド**:
   - `?stage=city_gs` でデスクトップ 3DGS レンダラーを強制作動
   - `?stage=city_glb` で GLB レンダラーを強制作動
3. **HUD 手動選択コントロール**:
   - 画面左上の HUD 内のドロップダウンで手動切り替えが可能（手動選択 > URLパラメータ > 自動判定 の優先順位）。
4. **フォールバック設計**:
   - `latest.json` が未生成、モデル取得失敗、または未対応フォーマットの場合、手続き型生成のプレースホルダー街が表示され、HUD にステータス理由が明記されます。
5. **GPU リソース解放**:
   - ステージ切替時にジオメトリ、マテリアル、テクスチャ、および 3DGS ソートバッファ/ワーカーの完全破棄（`dispose`）を行います。

## サポートライブラリ・対応フォーマット

- **3DGS レンダラー**: `@mkkellogg/gaussian-splats-3d` (v0.4.4 - jsdDelivr CDN 経由 pinned)
- **対応 3DGS フォーマット**: `.ply`（Colabバッチ生成物）、`.splat`、`.ksplat`
- **Three.js バージョン**: `0.162.0` (pinned)
